# daily-briefing

공개 원제공자의 무료 API·공식 페이지를 직접 수집하는 GitHub Pages 브리핑입니다. 다른 브리핑 사이트를 읽거나 실패 시 그 사이트의 내용으로 채우지 않습니다. 유료 AI 논평의 버튼·기존 캐시·수동 재생성 설정은 유지합니다.

## 자동 갱신과 표시

- `.github/workflows/daily.yml`: 한국시간 매일 06:30~21:30, 1시간 간격(하루 16회). GitHub 예약 실행은 지연될 수 있습니다.
- `scripts/generate_briefing.py`: `briefing.html`과 `index.html` 생성. 항목별 실패를 격리합니다.
- 모든 뉴스는 네이버 뉴스·네이버 엔터에서 직접 수집하며 제목/복사 내용에 네이버 원래 기사 주소를 사용합니다. 단축 주소는 새 콘텐츠에 사용하지 않습니다.
- 뉴스 첫 줄은 `💕 [열애·결혼 소식]`, 둘째 줄은 `26년 10월 17일 토요일` 형식입니다. 복사 내용에도 유지합니다.
- 데이터의 실제 기준일·집계기간을 보존합니다. 수집일을 원자료 기준일로 바꾸지 않습니다.

## 무료 직접 출처

| 항목 | 직접 읽는 제공자 | 표시 기준 |
|---|---|---|
| 운세 | 지윤철학원 공개 게시판 | 당일 게시물 |
| 날씨 | Open-Meteo 공식 공개 API | 당일 예보 |
| 뉴스 8개 | 네이버 뉴스·네이버 엔터 공개 목록 | 제목과 네이버 기사 원래 주소 |
| 청약 | 한국부동산원 청약홈 공고 페이지 | 접수 일정 |
| 주간 아파트 동향 | 한국부동산원 R-ONE 무료 API | 공식 통계 기준일, 직접 수집한 출처가 표시된 캐시만 허용 |
| 환율 | 유럽중앙은행 ECB 공식 XML | 공식 발표일·원화 교차 계산 참고값(은행 매매기준율과 다름) |
| 유가 | 한국석유공사 오피넷 무료 API | 무료 인증키 연결 시만 수치 표시 |
| 금·은·코인 | 네이버 금융·Yahoo Finance·CoinGecko 공개 API | 제공자 자료 직접 수집, 실패 시 다른 브리핑으로 대체하지 않음 |
| 베스트셀러 | 알라딘 공식 페이지·무료 TTB API | 주간 순위 |
| 부동산·생활 가이드 6개 | 법제처·국토교통부·공식 기관 공개 안내 | 상시 안내를 검토·요약한 편집 가이드, 일별 순환. 새 뉴스/시세로 표시하지 않음 |
| 아파트 실거래가 | 국토교통부 공식 공개 CSV | 최근 7일 계약, 해제 제외, 최신 12개 계약 사례 |
| 서울 상권 | 서울특별시 실시간 도시데이터 공식 공개 웹 JSON | 선택 4개 상권, 카드 소비 기준, 2시간 이내 자료 |
| 비트코인 공포·탐욕 | Alternative.me 공식 무료 API | 실제 UTC 기준일, 옆에 제공자 출처 명시 |
| 경제 문서 관심도 | Wikimedia Analytics 공식 무료 API | 고정 영어 문서 8개, 완전한 7일과 직전 7일 사용자 조회수 비교 |

상세한 API·출처는 `data-sources.json`을 봅니다. 유가 인증키가 없는 경우 수치가 없음을 표시합니다. 국토교통부 실거래가 공개시스템의 무료 CSV에서 전국 아파트 매매 계약 사례를 직접 수집합니다. 최근 7일 계약일 기준으로 해제 거래를 제외한 최신 12개 사례를 표시하며, 전국 거래량 통계·신규 등록 순위로 표시하지 않습니다. 빌드당 1회 다운로드하고 접근 오류나 일일 제한을 다른 세션으로 회피하지 않습니다. 유료 API/유료 플랜으로 대체하지 않습니다.

## 선택 무료 인증키

- `RONE_KEY`: 한국부동산원 R-ONE. 기존 GitHub Actions Secret을 유지합니다.
- `ALADIN_TTB_KEY`: 알라딘 무료 TTB. 기존 Secret을 유지합니다.
- `OPINET_KEY`: 오피넷 무료 유가 API. 미등록이면 유가 수치를 표시하지 않습니다.
- 키 값은 페이지·출처 파일·로그에 기록하지 않습니다. 새로운 계정·유료 서비스는 생성하지 않습니다.

## AI 논평

기존 `comment-cache.json`의 6개 결과를 그대로 보존합니다. 이번 출처 변경에서는 논평·유료 설정을 수정하지 않으며 검증 실행은 `refresh_comments=false`로 수행합니다. 기존 `AI 논평 새로 받기` 수동 기능은 유지됩니다. 유료 API를 사용하는 수동 재생성은 이번 작업 범위에 포함되지 않습니다.

## 본문과 출처의 복사 구분

모든 카드의 자료·출처와 근거 URL은 본문 상자 바깥의 하단에 표시합니다. 복사 버튼은 본문만 복사하며, 뉴스 기사 원문 주소와 본문 안의 공식 조회 링크는 유지합니다. 경제 문서 관심도에는 조회수·증감률·중복 조회의 의미를 설명합니다.

## 추가 부동산 콘텐츠

- 공공임대 모집공고: 마이홈포털 공식 공개 검색에서 최근 2개월 모집중 공고 최대 5개를 읽고 실제 공고일·공급기관·정정 여부와 원문 링크를 표시합니다. 모집중과 당일 접수 가능을 구분합니다.
- 전세보증금 지키기: 매 실행 HUG의 전세보증금반환보증 공식 상품 페이지에서 신청기한·대상주택·보증금 요건을 읽습니다. 상품 페이지에서 연결한 관련 공지의 제목과 실제 작성일도 확인합니다.
- 내집마련 대출 정보: 매 실행 한국주택금융공사의 보금자리론·디딤돌대출 상품 조건과 금리 표를 읽습니다. 현재 한국시간 월과 공식 금리 기준월·공시일을 확인하고, 실제 표의 금리와 한도·대상 조건을 표시합니다. 개인별 승인이나 적용 금리를 계산한 결과는 아닙니다.
- 토지·규제 최신 고시: 매 실행 국토교통부 토지이음의 최근 공식 고시를 읽고 고시일·고시번호·담당기관과 원문 링크를 표시합니다. 고시 목록은 개별 필지의 규제 적용 여부를 판정한 결과가 아닙니다.

위 4개는 기존 자동 갱신 작업(한국시간 06:30~21:30 매시간)에서 직접 수집합니다. 원자료의 게시일·공시일과 수집 시각을 구분하며, 접근 또는 표 구조 확인에 실패하면 최신 내용 확인 실패를 표시합니다. 이전의 고정 안내문이나 확인하지 못한 수치를 최신 자료처럼 표시하지 않습니다. 자료·출처는 카드 아래에 보존하고 복사에서는 제외하며, 고시·모집공고의 원문 링크는 복사 본문에 유지합니다. 모든 수집은 무료이며 유료 AI 논평은 재생성하지 않습니다.
